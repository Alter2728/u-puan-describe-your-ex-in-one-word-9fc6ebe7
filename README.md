One word that sums up an ex, entered in the [make.fun](https://make.fun/bounty/u-puan-describe-your-ex-in-one-word-9fc6ebe7) bounty "Describe Your Ex in One Word". A judge model reads the words two at a time and picks the funnier one — the five funniest words share the $2 pool.

> "Uninstalled"

## Run it

```sh
python3 main.py
```

This writes the entry word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. Python 3 standard library only, deterministic — running it twice produces byte-identical output.
